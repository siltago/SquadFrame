# Modo de campo

Ambientes, elementos, medidas e observações são gravados primeiro no Room. A UI reage imediatamente ao banco. Elementos podem ser duplicados; copiar estrutura cria medidas provisórias com valor zero, nunca valores confirmados.

Medidas aceitam vírgula ou ponto, preservam unidade e permitem os estados provisória, confirmada, revisar e invalidada. Negativos são aceitos somente para nível e prumo. Observações mantêm no máximo um alvo específico e categorias críticas recebem o mesmo estado persistente das demais entidades.
