# Navegação

Fluxo atual: login → visitas → modo de campo → seleção de ambiente → seleção de elemento → medidas e observações. A tela de sincronização é acessível pelo topo e apresenta pendências, erros, conflitos, tentativas e ação manual.

O modo de campo exibe obra, cliente, endereço, status, progresso confirmado, última sincronização e quantidade de alterações pendentes. As transições disponíveis são iniciar, pausar, retomar e enviar para revisão.
