# Setup

Requisitos: Android Studio atual, JBR 17–26, SDK Platform 37.0 e Build Tools 36.0.0. Defina fora do Git em `~/.gradle/gradle.properties`:

```properties
SQUADMEASURE_SUPABASE_URL=https://projeto.supabase.co
SQUADMEASURE_SUPABASE_ANON_KEY=chave_anon
SQUADMEASURE_API_BASE_URL=https://app.exemplo.com
```

Nunca use `service_role`.
